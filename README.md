# CITY RTS
A Real Time Strategy game inspired by Sid Meier's Civilization series (and some Roblox RTS games but shhh).

Heavily motivated by my friend NateDog. He loves these games.

## Installation
1. Go to the [latest release](https://github.com/wallwraf/CityBuilerStrategy/releases).
2. Install the cityrts.zip.
3. Extract its contents anywhere.
4. Run the cityrts.exe.
